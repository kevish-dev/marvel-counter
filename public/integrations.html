A Shields badge, if your README already uses them.

The shields endpoint is read-only, so it never changes your count. Use it next to other badges. The little pixel badge counts views like the full counter does.


      

  


  

    
Show the number as text, too.

      
A small GitHub Action rewrites a line in your README with your current count, once a day. Add the two marker comments where you want the number, then add the workflow.

    

      

      

  


  

    
Or just read the number.

      
The JSON endpoint allows any website to call it. It never counts a view.
