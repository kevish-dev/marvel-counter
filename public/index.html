GitHub profiles, GitLab READMEs, Notion pages, and your own site. It is a plain SVG, so there is nothing to install.

        
Need the number itself? Read it as JSON from any page. It never increments the count.

      

      

        


# read a count
curl https://herocount.kevish.dev/c/your-id.json

# response
{ "id": "your-id", "count": 1204 }
