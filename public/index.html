Seven heroes, seven small tricks.

Each one holds a digit and does one thing on a loop. Pick any order, or let them cycle.

Make yours in a minute.

Counts page loads, not unique people. Your count starts at zero.

/c/

Letters, numbers, - and _. A GitHub username works well.

Works anywhere an image does.

        
GitHub profiles, GitLab READMEs, Notion pages, and your own site. It is a plain SVG, so there is nothing to install.

        
Need the number itself? Read it as JSON from any page. It never increments the count.

      

      

        


# read a count
curl https://herocount.kevish.dev/c/your-id.json

# response
{ "id": "your-id", "count": 1204 }

# options on the image URL
?theme=dark|light|auto|clear
&digits=3..9
