Quick start

The whole thing, in four steps. The guides below just say where to paste.

  1. Open the home page

    Go to herocount.kevish.dev and scroll to "Make yours in a minute".

  2. Type an id and press Create counter

    Your GitHub username is a good id. Letters, numbers, - and _ only.

  3. Save your edit key

    A key that starts with hck_ appears once. Copy it into a password manager. It lets you see stats and reset the counter later.

  4. Copy the Markdown snippet

    It looks like this. Paste it wherever you want the counter.

Add it to your GitHub profile

      
Your profile README is the page people see at github.com/your-name.

      
    
        
  1. Find or make your profile repository
    It is a public repository named exactly like your username. If you do not have one, open github.com/new, type your username as the name, keep it Public, tick "Add a README file", and press Create repository.
    2. 
        
  2. Open README.md and press the pencil icon
    That opens the file for editing in your browser.
    3. 
        
  3. Paste the snippet where you want the counter
    This version switches between dark and light with the visitor's theme.
    
          
    4. 
        
  4. Press Commit changes
    Add a short message like "Add visitor counter" and confirm.
    5. 
        
  5. Visit your profile
    Open github.com/your-name. The heroes show up and count every view from now on.

Change the look

      
Add options to the end of the image address. Join several with &. The easiest way is the generator on the home page, which writes them for you.

      

        
theme
dark, light, auto (follows the visitor), clear (no background)

        
pack
classic, marvel, dc, anime, retro, critters

        
heroes
Your own order, for example batman,goku,cat

        
format
plain (0001204), sep (1,204), compact (1.2K)

        
digits
3 to 9, for the plain format

        
since
1 adds "since oct 2026" under the heroes

        
milestone
0 turns off the confetti at 100, 1,000, 10,000 views and more

      

      

        

          

        

          

      

    


    

      
Show the number as text

      
A small GitHub Action writes your count into the README once a day, as plain text.

      
    
        
  1. Add two markers to your README where the number goes
    
          
    2. 
        
  2. Create the file .github/workflows/visitors.yml with this content
    
          
    3. 
        
  3. Run it once
    Open the Actions tab, pick "Update visitor count" and press Run workflow. After that it runs every day by itself.

Your edit key and stats

      
    
        
  1. Open the dashboard
    Go to Dashboard, type your id and paste the edit key you saved.
    2. 
        
  2. Read your numbers
    Total views, today, the last 7 days, a 30-day chart and the sites that sent visitors.
    3. 
        
  3. Reset, rotate or delete if you need to
    Rotate gives you a new key and the old one stops working. Delete removes the counter for good.

If something looks wrong

      

        
The counter does not show up 
Check that the id in the snippet matches the one you created. Open the image address in a new tab: if it says "not found", make the id on the home page first.

        
The number did not go up when I refreshed 
GitHub and some browsers keep a copy of the image for a moment. Wait a minute and refresh again. One network can add at most 120 views a minute to a counter, so rapid refreshing stops counting.

        
Does it count unique people? 
No, it counts page loads. Crawlers and link previews are not counted.

        
I lost my edit key 
It cannot be recovered, because we only store a fingerprint of it. Your counter keeps working; you just cannot open its stats. Make a new id if you need a dashboard.

        
The id I want is taken 
Pick another, such as your name plus a word. If it is yours from before, press Use this id or Claim it on the home page.

        
Can I run HeroCount on my own server? 
Yes, with a license after a 7-day evaluation. See Pricing.
